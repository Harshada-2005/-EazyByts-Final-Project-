# 🎟️ Event Manager Website

A simple and responsive **Event Management** web application built with **HTML**, **CSS**, and **JavaScript**. This project allows users to browse events, view event details, and book tickets. Bookings are saved locally using the browser's local storage.

## 🚀 Features

- 🎫 View upcoming events
- 📝 Book and save events
- 📋 Dashboard to manage bookings
- 💡 Interactive UI with animations
- 📱 Responsive design for mobile and desktop

## 🛠️ Tech Stack

- **Frontend**: HTML, CSS, JavaScript
- **Storage**: Browser Local Storage (for bookings)
